# UMA UX/UI Audit

- **Trigger:** Activarse cuando se pida revisar, auditar o mejorar la experiencia visual/general.
- **Restricción:** No editar archivos durante una auditoría.
- **Alcance:** Revisar home, header, hero, catálogo, filtros, cards, ficha individual, WhatsApp, footer y responsive móvil.
- **Criterios de Evaluación:** Evaluar jerarquía, contraste, legibilidad, espaciado, navegación, claridad comercial, percepción de marca y accesibilidad.
- **Diagnóstico Estético:** Identificar qué se ve viejo, qué se ve plano, qué se ve premium y qué debe conservarse.
- **Entregable:** Entregar diagnóstico honesto.
- **Propuestas:** Proponer máximo 3 rutas visuales.
- **Detalle de Propuestas:** Para cada ruta incluir paleta, uso del beige, uso del vinotinto/cacao, tipografía, cards, botones, filtros, ventajas y riesgos.
- **Cierre:** Terminar con una recomendación final y plan por fases. Separar cambios urgentes, cambios deseables y cambios para después.
- **Validación Visual:** Cuando sea posible, auditar contra la URL de producción o capturas reales, no solo contra el código. Si no hay capturas o navegación visual disponible, declarar la limitación antes de opinar.
- **Categorización de Problemas:** Separar claramente problemas de UX, problemas de UI, problemas de dirección de arte y problemas técnicos.
- **Justificación de Cambios:** No proponer cambios genéricos; cada recomendación debe explicar qué mejora y qué riesgo tiene.
