# UMA Design Director

- **Marca:** UMA Mercado Consciente es una marca de bienestar, cosmética natural, mercado consciente y productos botánicos/artesanales.
- **Identidad Visual:** La marca debe sentirse premium, contemporánea, editorial, cálida y boutique.
- **Colores Base:** Conservar como base el vinotinto/cacao y el beige, pero evitar que la combinación se vea vieja, pesada o apagada.
- **Uso del Beige:** Usar el beige como base cálida, no como único fondo dominante.
- **Uso del Vinotinto/Cacao:** Usar el vinotinto/cacao con intención: CTAs, contraste, detalles editoriales, títulos o bloques puntuales.
- **Acentos Sofisticados:** Explorar acentos sofisticados: marfil limpio, salvia, oliva seco, arcilla, arena, miel, gris cálido o negro cacao.
- **Anti-patrones:** Evitar estética genérica, plantilla antigua, web de catálogo viejo, sombras anticuadas, exceso de cajas, bordes duros o fondos demasiado planos.
- **Prioridades Visuales:** Priorizar aire, jerarquía, fotografía, textura sutil, composición editorial y sensación de e-commerce boutique.
- **Flujo de Trabajo:** Antes de cambiar diseño, proponer rutas visuales y pedir aprobación.
- **Guía Visual Previa:** Antes de tocar CSS o componentes, proponer una mini guía visual con: paleta refinada, jerarquía de color, uso de fondos, tratamiento de cards, tratamiento de botones, tratamiento de filtros y tratamiento tipográfico.
- **Paleta de Colores Moderna:** Evitar depender solo de beige + vinotinto; usar marfil, cacao, salvia, arena o acentos suaves para modernizar.
- **Sensación General:** El resultado debe sentirse boutique, actual y comercial, no solo bonito/editorial.
